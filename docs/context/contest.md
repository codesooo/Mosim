## 2. 개발 산출물 제출 규칙

- 개발 산출물(시연 영상, Git 저장소 링크, 소스 코드, APK)은 **선택이지만 가산점**이 있다.
- 아이디어 특별상을 포함해 **수상팀은 개발 산출물을 반드시 제출**해야 한다.
- APK는 이메일 첨부가 아니라 **Git 저장소의 APK 폴더나 릴리스 링크**로 제출한다.
- 저장소 `README.md`에 반드시 있어야 하는 항목:
  1. 앱 이름
  2. 실행 방법
  3. 테스트 환경과 필요한 설정
  4. APK 위치 또는 릴리스 링크
- 비공개 저장소도 되지만, 심사용 계정을 협력자로 초대하고 마감 전에 접근되는지 확인해야 한다.
- 마감 전 수정 제출이 가능하다. 마감 전 마지막 제출본이 최종본이다.

**코딩 시 지킬 것**

- README의 위 4개 항목을 지우거나 깨뜨리지 않는다. 실행 방법이 바뀌면 README도 같은 PR에서 고친다.
- 공유 링크와 첨부자료에 **개인정보, 계정정보, 개발자 실명**이 노출되면 안 된다.
  코드, 주석, 커밋 메시지, README, 스크린샷, 시연 영상에 넣지 않는다.
- `[확인 필요]` Git 커밋 작성자 이름(author)도 실명 노출로 볼 수 있다. 저장소 공개 전에 팀이 결정한다.

## 3. 심사 기준

기능을 추가하거나 우선순위를 정할 때 이 네 가지로 판단한다.

| 기준 | 심사에서 보는 것 | 개발할 때 판단 기준 |
|---|---|---|
| 차량 특화성 | 모바일과 다른 차량만의 가치, 주행·정차 맥락, 차량 데이터·하드웨어 활용 | 이 기능이 차량 데이터나 주행 상황과 연결되는가? 폰 앱으로도 똑같이 되면 우선순위를 낮춘다 |
| 창의성 | 문제 정의가 분명한가, 해결이 독창적인가 | 모심의 문제(출발 전 판단, 동승자 케어)에 직접 기여하는가? |
| 기술 활용성 | Pleos SDK·API를 핵심 기능과 UX에 적절히 활용 | 많이 쓰는 것보다 **핵심 기능에 꼭 필요한 SDK**를 실제로 연동하는 것이 중요하다 |
| 사업성 | 목표 고객, 지속 이용, 확장 가능성 | 개인화 데이터 축적(쓸수록 좋아짐)이 보이게 만든다 |

주최 측 권장 전략: 처음부터 다 만들지 말고 **차량 환경에서만 줄 수 있는 핵심 가치 하나를 실제로 동작하게** 만든다.

`[확인 필요]` 기술 활용성 심사에서 Mock만으로 동작하는 데모가 어떻게 평가될지는 알 수 없다. 핵심 시나리오 하나는 실제 SDK로 연동하는 것을 목표로 한다.

## 4. 생성형 AI 사용 규칙

- 기획과 개발에서 생성형 AI를 보조 도구로 쓸 수 있다.
- 단, **참가자가 전체 구조와 로직을 이해하고 최종 PT 기술 질의응답에서 직접 설명**할 수 있어야 한다.

**코딩 시 지킬 것**

- 팀원이 설명하지 못할 코드를 만들지 않는다. 단순한 구조를 고른다.
- 중요한 설계 결정은 `docs/architecture.md`에 이유와 함께 남긴다.
- PR 설명에 무엇이 어떻게 동작하는지 적는다.

## 5. 시연·테스트 환경

- **실제 차량 시연은 지원하지 않는다.** 검증과 시연은 Pleos Connect 에뮬레이터로 한다.
- Virtual Console로 기어, 도어, 좌석 탑승, 배터리, 공조 같은 차량 상태를 바꿔 가며 시연할 수 있어야 한다.
  데모 시나리오는 Virtual Console 조작으로 재현 가능하게 설계한다.
- 일상 화면 개발은 일반 Android 에뮬레이터로 충분하다(README 참고).

## 6. 그 밖의 규칙

- 팀은 최대 5명. 같은 팀이 다른 작품을 여러 개 낼 수 있다.
- 외부 API와 공용 네트워크를 함께 써도 된다.
- 개발 단계에서는 SDK 사용 승인 없이, 문서에 있는 권한을 매니페스트에 선언해 에뮬레이터에서 테스트할 수 있다.
  실제 Pleos App Market 배포는 승인된 권한만 허용된다.
  `[확인 필요]` 공모전 제출 APK에 App Market 권한 기준이 적용되는지. 일단 **실제로 쓰는 API의 최소 권한만** 선언한다.
- 숏폼 챌린지(선택, 본상과 별도): 30초~1분, 인스타그램 릴스나 유튜브 쇼츠, 해시태그 2~3개 이상.
  상금은 설명회에서 500만 원과 50만 원이 섞여 안내됐고, 참가신청서에는 50만 원으로 적혀 있다. `[확인 필요]`
  차량 내·외부 이미지 노출은 최소화하고, 저작권·초상권은 응모자 책임이다.
