## 1. App Review Guidelines 개요
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/ -->

Pleos App Market은 운전자·탑승자 안전을 최우선으로, **운전자 주의 분산 요소**와 **사이버보안 위협 요소**를 심사에서 중점 검증합니다. 운행 안전에 위험이 될 수 있다고 판단되면 거부될 수 있으며, 가이드 전반을 준수해도 추가 위험 요소가 있으면 거부될 수 있습니다.

심사 영역: ① 콘텐츠 안전성 ② 앱 기능 및 성능 안정성 ③ 운전자 주의 분산 요소 최소화 설계 ④ App Market 등록정보 ⑤ 사용자 개인정보 및 보안

## 2. 앱 기능 및 성능 안정성 ⭐
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/review-functionality-performance-stability -->

### 완성도
- 설치·삭제 오류 없음(인증 키 누락, 파일 누락, 삭제 후 잔여 파일 등)
- 실행 오류 없음(강제 종료, 하드웨어 재시작 등)
- 기능 사용 오류 없음(화면 멈춤, 기능 미동작, 터치 미인식)
- 미디어 정상 출력(사운드 끊김, 그래픽 깨짐 없음)
- **제출 앱 = 실제 서비스 앱**: 테스트용 더미 데이터·임시 파일·임시 콘텐츠 금지
- 왜곡·흐림·모자이크 없는 UI, 디스플레이 컷아웃·인셋·키보드·시스템 표시줄 등 안전 영역 준수
### 기능 및 성능 기준
- 카테고리에서 벗어난 기능이나 서비스와 다른 카테고리 선택 시 거부 가능
- 스터터링·프레임 저하·화면 끊김 등 심각한 성능 저하 금지, 시스템 성능 저하 유발 금지
- **입력 후 응답(터치 효과 애니메이션까지) 0.25초 이내**
- **앱 실행 10초 이내, 콘텐츠 로드 10초 이내, 버튼 반응 2초 이내** (2초 안에 못 하면 동작 중임을 UI로 표시)
- 백그라운드에서 돌아오면 마지막 상태 복원(수 시간 이상 미사용 시 기본 상태 시작 가능)
- (성능 수치 기준: CPU 주행 중 5% 미만 / 정차 중 25% 이하, RAM 400MB 이하 — 05 기획 가이드 9절)
### 하드웨어·소프트웨어 손상 금지
과점유로 인한 성능 저하 포함 금지. 사용자에게 기기 재시작이나 핵심 기능과 무관한 시스템 설정 변경을 요구하면 안 됨.

### SDK·API 사용 심사
- 차량 상태를 바꾸거나 운전 안전에 영향을 주는 SDK·API는 별도 심사 기준 적용.
- **Vehicle SDK 퍼미션은 App Market과 사전 협의·승인된 경우에만 선언 가능. 승인되지 않은 퍼미션을 선언하면 심사 불통과.**
### 디스플레이 호환성
- 레터박스 없이 디스플레이 영역을 최대한 채울 것(미세 비율 보정용 한 방향 레터박스만 허용), 호환성 모드 실행 금지
- 해상도 전환 시 상태 손실·화면 이상 없음(이미지 늘어짐, 앨리어싱·블러, 터치 영역과 버튼 위치 불일치 금지)
- 모든 화면 상태에서 같은 기능을 노출(기능 패리티), 화면 전환 시 버튼·기능이 바뀌지 않고 비율에 맞게 이동

## 3. 운전자 주의 분산 요소 최소화 설계 ⭐
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/review-driver-distraction-elements -->

Pleos Connect UI Design Guide를 반드시 사전 확인 후 제출.

### 미디어 앱(동영상·게임·브라우저 기능을 갖는 앱)
- **운전 중 실행·사용 불가, 정차 중에만 사용 가능.** 운전이 시작되면 사용 일시 중지·UI 숨김, 운전 중에는 '일시 중지' 해제 불가.
- 백그라운드에서 복귀 시 마지막 상태 복원(수 분 이내 복귀면 최대한 가깝게, 수 시간 이상이면 기본 상태 가능).
- 모든 미디어 항목에 한눈에 들어오는 제목·썸네일, 부적절한 미리보기 금지.
- 헤드업 알림 게시 금지(운전과 무관한 알림 금지).
- 동영상 앱은 미디어 세션과 통합(동시 다중 미디어 불가, 재생/일시정지/중지 지원).
- 브라우저 앱은 비밀번호·결제 정보 저장/허용 금지(프로필 잠금으로 차단 가능한 경우 예외). 동기화 시 인증 메시지 표시와 차량 화면 안내 필요.

## 4. Pleos App Market 등록정보 (요약)
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/review-app-registration-info -->

- 기본 정보(이름, 설명, 개발자 이름, 아이콘, 이미지)는 정확하고 부적절한 내용이 없어야 함. 실적·순위 등 확인 어려운 내용, 텍스트 이모티콘·반복 특수문자 금지.
- **앱 제목 30자(영문 기준) 이하**, 타 앱과 유사·중복·오해 소지 금지.
- 서비스 국가별 언어로 메타데이터 작성. 카테고리가 부적합하면 임의 변경될 수 있음.
- **앱 아이콘**: 최대 1 MB, 512×512 px, PNG/JPEG
- **앱 이미지(스크린샷)**: 최소 2장~최대 8장, 장당 최대 8 MB, 2560×1380 / 1700×1212 / 840×1212 px, PNG/JPEG (예: 기능 사용 전/후, 앱만의 기능 화면). 실제 앱과 다르면 거부 가능.
- **패키지: APK, 압축 기준 600MB 미만**
- 연령 등급은 콘텐츠에 맞게(IARC 연계 심의).
- 개인정보 처리 과정, 접근 권한(카메라, 저장 공간, 마이크, GPS, 전화, 연락처 등), 위치 정보 활용, 광고성 정보 전송 여부를 정직하게 입력. 개인정보처리방침 필수, 위치정보 사용 시 '위치정보 이용약관 및 기타 정보 처리방침'도 제출.
- 로그인이 필요하면 모든 기능에 접근 가능한 **실제 사용자 기준 계정** 제출.
- 증빙: 타사 지적재산권 사용 권리, 정부 기관 관련 앱, 웹 앱의 도메인 등록 증빙, 의료 기관 권한, 성인용 게임 GRAC 등급 등.

## 5. 콘텐츠 안전성 (요약)
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/review-content-safety -->

- 과도하게 선정적·폭력적이거나 불쾌감을 주는 콘텐츠, 사용자에게 정신적·신체적·금전적 피해를 줄 수 있는 콘텐츠 금지. OTT·웹툰·UGC 플랫폼은 필터링과 신고 채널 필요(공익·ESDA 목적은 예외 가능).
- **안전을 저해하는 콘텐츠 금지**: 음주 운전·과속·신호 위반 등을 권유·미화하는 내용. 주류 광고는 현지 광고법 준수 + 음주 운전 위험 경고.
- 선정적·폭력적·위험(자살·자해 조장, 아동이 차 밖으로 신체를 내밀도록 유도 등)·불법·사행성·차별·민감 사안 악용 콘텐츠, 승인되지 않은 물품 금지.
- 미성년자·아동 보호: 인증 없이 보이는 화면·썸네일 등은 '전체 이용가'만.
- 지적재산권 침해 금지(신고 시 다운로드 차단, 소명 실패 시 영구 제외 가능).
- **사용자 제작/AI 생성 콘텐츠**를 쓰는 앱은 부적절한 콘텐츠 필터링과 신고 기능 포함 필요.
- 암호화폐 채굴 앱 거부, 확률형 아이템은 구입 전 확률 공개.

## 6. 사용자 개인정보 및 보안 (요약)
<!-- 원문: /docs/pleos-only/distribute/app-review-guide/review-user-privacy-security -->

- 접근 권한은 서비스에 필요한 범위로 최소화. 수집 항목·목적·보유기간·거부 권리를 고지하고 **명시적 동의** 절차 구현. 목적 외 사용 금지, 개인정보 처리방침 공개, GDPR 등 국가별 법령 적용. 위치정보 서비스는 등록/신고 확인을 요청받을 수 있음.
- **투명성**: 접근·수집·사용·공유 데이터 목록과 방식을 앱 안에서 명확히 표시.
- **동의 요구사항**: 동의/거부 화면은 명확해야 하며, 동의 버튼 외 동작(뒤로가기, 빈 공간 터치 등)을 동의로 간주 금지. 허가한 항목 데이터에만 접근. 아동 개인정보는 법정 대리인 동의.
- **보안**: 바이러스·스파이웨어·트로이 목마·애드웨어·루팅, 스팸·DDoS·크립토재킹, 피싱·사기광고 등 금지. 보안 기능 우회·무력화 금지. 동의 없는 데이터 탈취·보관·광고 활용·제3자 전송 금지. 사용자가 동의를 철회하면 즉시 활용을 끊고 저장 데이터 삭제.

## 7. 앱 심사 제출
<!-- 원문: /docs/pleos-only/distribute/app-submission-guide -->

### 제출 전 준비
1. 개발자 정보 최신화(심사팀이 언제든 연락 가능한 연락처)
2. 기능 테스트: 실행 불가, 크래시, 성능 저하, 버그, 이미지 깨짐·해상도 늘어짐, 과부하·배터리 소모
3. 보안: 취약점, 멀웨어·바이러스·악성 코드 확인(앱 보안 가이드 참조)
4. 앱 정보·메타데이터: 명칭, 버전명, 카테고리, 출시 국가, 연령 등급, 접근 권한, 개인정보 처리, APK·아이콘·스크린샷, 약관·처리방침
5. 심사팀이 모든 기능을 확인할 수 있도록 필요한 정보·계정 제공
6. 외부 서버 연결이 필요하면 제출 전 운영 구성 요소 활성화
7. 운전자 안전 고려 설계 확인
8. 출시 국가 법률·규제 준수(증빙 필요)
9. 연령 등급에 맞는 콘텐츠(IARC 등급 증적 제출, 한국 게임은 게임물관리위원회 심의)
10. 설명이 필요한 기능은 심사 노트에 주석·사용 설명서 첨부

### 앱 업데이트 관리
심사 통과 후에도 품질·서비스 상태를 유지해야 합니다. App Market은 주기적으로 샘플링 모니터링하며, 심각한 오류 보고·장기간 미업데이트·다수 신고 앱은 재심사 후 제외될 수 있습니다.
